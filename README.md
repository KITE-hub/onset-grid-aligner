# onset-grid-aligner

音源（ドラムステム）のオンセット（アタックの頭）が拍グリッドに対して何msずれているかを1msオーダーで推定し、0ms開始の音源を何ms移動すればグリッドに揃うかを解析・推定するPython CLIツールです。

## 主な用途

- 音源（ドラムステム）のオンセットがグリッドより前後どちらに何msずれているかを推定
- 推定方式ごとの「音源を何ms後ろに移動すればよいか」を候補として並列表示

## 必要環境

- Python 3.10+
- NumPy
- SciPy
- SoundFile
- FFmpeg (mp3/wmaを扱う場合)

## インストール

```bash
python -m pip install -r requirements.txt
```

## 使い方

BPM を指定して解析 (--bpm):

```bash
python src/onset_grid_aligner.py input.wav --bpm 120
```

BPM を自動推定:

```bash
python src/onset_grid_aligner.py input.wav
```

主なオプション:

```text
--bpm BPM BPMの指定
--bpm-min BPM推定範囲の下限
--bpm-max BPM推定範囲の上限
--low-hz 周波数帯域の下限 {デフォルトは1000、全方式に適用}
--high-hz 周波数帯域の上限 {デフォルトは12000、サンプルレートの半分未満にする必要があります、全方式に適用}
--head-level オンセット頭の定義 {デフォルトは0.15、全方式に適用}
--drift-window-sec 時間ドリフト解析の窓長
--no-band-check 帯域別検算を無効化
--no-refine 局所精密化を無効化
--filter-mode {zero,causal} (envelopeのバンドパスフィルタのみ)
```

## 対応する入力音声形式

直接読み込み:

- WAV
- FLAC
- AIFF / AIF
- OGG

FFmpeg 経由:

- MP3
- WMA

## 結果の読み方

出力に並ぶ方式別の候補[ms]は、0ms開始の音源をグリッドへ合わせる移動量を意味します。方式ごとに推定結果が異なることがあるため、単一の推奨移動量は表示しません。

符号は次の意味です。

- 正: 音源を後ろへずらす (遅らせる)
- 負: 音源を前へずらす

ドリフト回帰(指定したBPMと、検出したBPMとのズレ)が有効な場合は、各方式の候補値を音源の中央時点に換算します。

## 補正候補の方式の説明

主な候補は `envelop`、SuperFlux風、複素領域、HFC、Wavelet多重スケール、Wavelet粗スケールの6方式で、方式ごとに推定結果が異なることがあるため、単一の推奨移動量は表示しません。
位相の枝(拍内のどの固定線に乗っているか)は、位相ヒストグラムの得点が首位の60%以上、かつ拍内位置の事前の期待に基づく支持度が最良の80%以上の候補のうち、位相の絶対値が最小のものを選びます。0ms開始の音源のずれが±30ms程度に収まる前提のため、これを大きく超えるズレでは別の枝が選ばれることがあります。

各補正候補の特徴は次の通りです。

- `envelop`: 指定帯域の振幅包絡線から、立ち上がり比率（head-level）に達した時刻をオンセットとして検出する方式です。4分, 8分, 12分(8分3連), 16分, 24分(16分3連), 32分音符を複合した固定格子(1拍を24分割した12位置)への位相分布から代表位相を特定し、全方式が共有する「位相の枝」を決める基準にもなります。
- SuperFlux風: 短時間フーリエ変換（STFT）の対数振幅スペクトルに対し、過去フレームの最大値フィルタとの差分を計算する手法です。ピッチ変化やビブラートに伴う不要な立ち上がりを抑え、急峻なスペクトル増加のピーク位置を捉えます。
- 複素領域: STFTの複素スペクトルを用い、前2フレームの位相変化から予測した複素スペクトルと実測値との偏差を評価する方式です。ピーク到達待ちによる遅延を抑えるため、動的しきい値を立ち上がり側で横切る時刻を線形補間で特定します。
- HFC: STFTの複素スペクトルを用い、高周波成分ほど大きな重みを与える高周波エネルギー比率の変化量を評価する手法です。スネアやハイハットなど、高域に鋭い過渡成分を持つアタックに対して敏感に反応します。
- Wavelet多重スケール: 中心周波数を変えた複数の複素Gaborウェーブレットの包絡線から、局所ピークに対する相対的な立ち上がり率を求めます。0.3ms, 0.6ms, 1.2msの3スケールで平滑化した過渡強度の幾何平均を用い、サンプル精度の時間分解能で検出する構成です。
- Wavelet粗スケール: 複素Gaborウェーブレットの相対的な立ち上がり率を、1.2msの粗い時間スケールのみで平滑化する方式です。立ち上がりの判定が緩やかなためノイズに強い一方、急峻なアタック頭に対しては多重スケールよりも推定位置がわずかに遅れやすくなります。

## 注意

- 基本的にはドラムステムの音声ファイルの使用を前提としています。特に、生音源のアタックが弱いドラムを使用している場合や、音声ファイルがドラムステムではない場合は結果の信憑性が著しく落ちる可能性があります。
- 拍の分割・判定の仕様上、5連符や7連符には対応していません。
- 表示値の小数点以下すべてが測定精度を意味するわけではありません。
- オンセットの検出方法、周波数帯域、head-level、時間ドリフト、フィルタ方式、音源の構成によって結果が変化し得るため、出力される検算結果と推定誤差も確認してください。
- MP3はエンコーダ／デコーダ遅延の扱いが再生環境によって異なる場合があります。
